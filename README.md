# HisobFaktura2ProductList

Hisob-faktura (`.xls`, aslida HTML) fayllarini SmartPOS savdo saytiga
yuklanadigan `product_list` Excel shabloniga aylantiradigan desktop dastur.

`hisobfaktura_core.py` — dasturning asosiy mantiqi. Bu fayl har safar dastur
ishga tushganda (`launcher.py` orqali qurilgan `.exe`) internetdan avtomatik
yuklab olinadi — shuning uchun bu yerga kiritilgan har qanday o'zgarish
barcha ishlatuvchilarga (masalan, buxgalterga) qayta tarqatmasdan yetib
boradi.

Ishlatuvchilar `.exe` faylni faqat BIR MARTA olishlari kifoya.
